Команда:
&Sleep n
задерживает выполнение макроса на n секунд.

&SendBinary fn
посылает в ККТ содержимое файла fn без ожидания ответа.

&F1
для ЛБ

Начиная с версии 2.1.0:

Результаты выполнения макросов записываются в файл Fito_macro.log

В заголовке макроса (в первой строке, за [FITO Macro]) могут использоваться параметры:
Count=n - Макрос выполнится n раз подряд
Pause=n - После выполнения макроса выдерживается пауза n*100мс
Step - макрос выполняется пошагово(а не пакетно),  возникающая ошибка прерывает выполнение макроса
       есть возможность использовать условную команду (см. ниже)

Условная команда позволяет проанализировать ответ на предыдущую команду и имеет вид:

~ параметр условие значение
Параметр имеет вид : $n, где n - номер параметра (считается от 1) или 0 - код ошибки
Условие - одно из  =  <  >  <=  >=, параметры и значение интерпертируются как строковые
          Перед условием можно использовать символ !, для инвертирования условия
Значение - строка, с которой сравнивается параметр
При невыполнении условия макрос останавливается

Если первым символом в команде является '*', то возникающая ошибка не приводит к останову макроса
Если первым символом в команде является ';', то строка рассматривается, как комментарий
Последовательность символов $$R будет заменена на номер повтора чека (см. параметр Count)



Начиная с версии 2.1.0:
Реализован файл сценариев с расширением .mls вида:
[FITO Macro List] onerr=annul.mac
1.mac
2.mac

Макрос, указанный в строке onerr=, будет исполнен в случае возникновения ошибки

Начиная с версии 2.3.0:
Добавлена команда &SendMarkCode, выполняющая проверку кода маркировки в ИСМ командами 0x79/4 и 0x79/5

Начиная с версии 2.3.19:
Добавлена команда &SendGraphic, выполняющая загрузку картинок, дизайна и логотипа
Ее параметры:

&SendGraphic mode file offset pictID no
где mode - режим (0-загрузка логотипа, 1-печать BMP-картинки, 2- печать PNG-картинки, 3-загрузка BMP-картинки, 4-загрузка дизайна)
    file - файл картинки или дизайна
    offset - смещение картинки
    pictID - идетификатор загружаемой картинки
    no - номер загружаемой картинки
