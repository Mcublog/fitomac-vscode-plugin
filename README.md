# vscode-fito

Расширение VSCode для подсветки номеров параметров в макросах FITO для Пирит 2Ф
(файлы `.mac` и `.mls`).

## Возможности

После каждой `;` в строке команды рисуется маленький цифровой бейдж с номером
параметра. Пустые параметры (соседние `;;`) перестают сливаться — между ними
появляется цифра номера.

Синтаксическая подсветка: комментарии (строки, начинающиеся с `;` или `#`)
подсвечиваются тёмно-зелёным цветом. Служебные строки — заголовки `[...`,
специальные команды `&...` (`&Sleep`, `&SendBinary`, `&SendMarkCode`,
`&SendGraphic` и др.), условные `~...` и не-fatal префикс `*...` —
подсвечиваются мягким жёлтым цветом (независимо от цветовой схемы).

Пропускаются (не нумеруются):

- служебные строки: заголовок `[FITO Macro ...]` / `[FITO Macro List ...]`;
- специальные команды `&...` и условные `~...`;
- команды с префиксом `*`;
- строки-комментарии, начинающиеся с `;` или `#`;
- пустые строки.

Последняя `;` в команде — терминатор, бейдж для неё не рисуется. Поддерживаются
префикс `*` и плейсхолдер `$$R`.

## Запуск

```bash
cd fitomac-vscode-plugin
npm install
npm run compile
```

Затем в VSCode: `F5` (запустится Extension Development Host с этим расширением,
см. конфиг `.vscode/launch.json` и задачу `fito-compile`). Откройте любой `.mac`
из `resources/`.

### Ошибка `extensionHost is not supported` при запуске отладки

Ошибка `Configured debug type 'extensionHost' is not supported` означает, что
в вашем редакторе отключено/отсутствует встроенное расширение
**JavaScript Debugger** (`ms-vscode.js-debug`) — именно оно реализует тип
`extensionHost`.

Решение:

1. В VSCode нажмите `Ctrl+Shift+X` (расширения).
2. В поле поиска введите `@builtin js-debug`.
3. Если у расширения **JavaScript Debugger** есть кнопка **Enable** — нажмите её.
4. Если вместо этого кнопка **Disable** — расширение включено, попробуйте заново
   нажать `F5`, при необходимости перезапустите VSCode.

Если расширение вообще не найдено (например, в альтернативных редакторах на
базе VSCode) — установите его из marketplace либо используйте оригинальный
Microsoft VSCode.

## Сборка в VSIX

```bash
npm run package
```

Команда собирает расширение (через `vsce package`, перед этим выполняется
`vscode:prepublish` — компиляция TypeScript). Результат — файл
`vscode-fito-<версия>.vsix`, который можно установить через
`vscode --install-extension vscode-fito-<версия>.vsix`.

## Настройки

| Параметр | Описание | По умолчанию |
| -------- | -------- | ------------ |
| `fito.parameterBadges.enabled` | Вкл/выкл бейджи | `true` |
| `fito.parameterBadges.color` | Цвет бейджа (CSS) | `#8080809c` |

Цвета служебных строк (`#E5C07B`) и комментариев (`#3F7A3F`) зашиты в коде
расширения.

## Семантика нумерации

Как в утилите `fitomac` (`split_to_param`): `line.split(';')[:-1]` — первый
элемент это код команды, далее параметры с 1. Бейдж после `n`-й `;` показывает
номер начинающегося параметра.

Пример `30;2;67;Иванова;0;;`:
- `30` — код команды;
- бейджи `1 2 3 4 5` после первых пяти `;`;
- после `0` два `;;` — бейдж `6` между ними показывает пустой параметр 6.
